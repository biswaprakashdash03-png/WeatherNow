# WeatherNow 🌦️

A responsive weather dashboard built using HTML, CSS, and JavaScript. WeatherNow allows users to search for Indian cities and check current weather conditions and a 5-day forecast.

## ✨ Features

- 🌍 Search for Indian cities
- 🌡️ View current temperature and weather conditions
- 📅 Check the 5-day weather forecast
- 💧 View humidity and wind speed
- 🌡️ Check feels-like temperature
- ☀️ Display weather icons based on conditions
- 🌙 Toggle between light and dark modes
- 📍 Get weather information using your current location
- 📱 Responsive design for desktop and mobile devices
- 🔎 City search with autocomplete suggestions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather and geocoding APIs

## 📸 Project Overview

WeatherNow provides a simple and user-friendly interface for checking weather information. It displays current weather conditions and upcoming forecasts in a responsive dashboard.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Open the downloaded project folder in Visual Studio Code.

### 3. Run the Website

Open `index.html` in your browser, or use the Live Server extension in VS Code.
